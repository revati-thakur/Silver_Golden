# Gold & Silver Sales Analysis Dashboard 

## Project Overview
Developed an interactive Gold & Silver Sales Analysis Dashboard in Power BI to analyze sales performance, revenue trends, and product-wise insights. The dashboard provides KPI tracking, category analysis, and sales visualizations to support business decision-making.

## Key Features
- Gold and Silver revenue analysis
- Sales trend analysis by month
- Product category performance tracking
- Gold vs Silver sales contribution analysis
- Top and bottom selling products
- KPI monitoring and business insights

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Data Cleaning
- Data Visualization

## Dashboard Insights
- Total Revenue
- Product-wise Sales Performance
- Monthly Sales Trends
- Category Contribution Analysis
- Top Performing Products
